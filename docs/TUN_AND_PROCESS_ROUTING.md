# Маршрутизация Windows

Кнопка «Весь компьютер» выбирает `mode/System VPN.json` по стабильной роли,
а не первый TUN-профиль. Два маршрута `/1` покрывают IPv4 и имеют приоритет
над обычным маршрутом по умолчанию; локальные сети остаются в исключениях.
Игровые профили доступны через расширенные настройки.

Выбранные приложения хранятся в отдельном файле режима для каждой подписки.
`RoutingId` подписки не зависит от имени, URL и порядка серверов. Выбранный
режим запоминается по пути файла, поэтому сортировка списка его не сбрасывает.
Старый общий список приложений используется как начальный выбор при обновлении.

При отключении сначала останавливаются маршрутизация и DNS, затем Xray.
Оба потока журнала Xray завершаются до закрытия файла. Ошибка запроса AioDNS
возвращает SERVFAIL вместо передачи пустого ответа в нативную библиотеку.

Режим выбранных приложений использует `Redirector.bin` и NetFilter2. Имена исполняемых
файлов сопоставляются без учёта регистра: правило `discord\.exe` должно находить
`Discord.exe`, включая путь с каталогом версии. Проверка этого поведения находится
в `tests/RedirectorTester/ProcessMatcherTests.cpp`.
После подключения нужно полностью перезапустить ранее открытый Discord: фильтр
обрабатывает новые соединения, а существующие соединения автоматически не переносит.

Режим TUN запускает отдельный `bin/tun2socks.exe` v2.7.0 с комплектным Wintun 0.14.1.
Источник, лицензия и проверка SHA-256 архива находятся в `vendor/tun2socks`.
Старый `tun2socks.bin` не используется: он обращается к удалённым функциям Wintun
(`WintunFreeAdapter`, `WintunDeleteAdapter`), которых нет в современной библиотеке.
Остановка отдельного процесса обнаруживается приложением, его маршруты удаляются,
а интерфейс показывает ошибку. Вывод ядра сохраняется в `logging/tun2socks.log`.

Xray в режиме TUN привязывает исходящие соединения к физическому интерфейсу до
создания маршрутов, включая все узлы автоматического профиля. Это предотвращает
повторное попадание соединений самого Xray в туннель. Обрабатываются IPv4-маршруты
выбранного режима; поддержка IPv6 не добавлялась. Настройки DNS сохранены: встроенный
AioDNS или пользовательский DNS. Метрика физического интерфейса не изменяется.

Проверка конфигураций Xray и запрос через SOCKS не подтверждают системную маршрутизацию.
Для полной проверки TUN нужны права администратора: подключение, доступ к сайтам,
отключение и проверка удаления маршрутов. Если запуск не удался, нужны журналы
`logging/netch.log` и `logging/tun2socks.log`.
